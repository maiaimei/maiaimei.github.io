# 交互式终端（psql）

# 1. 最简登录方式

psql
1

前提条件：当前系统用户与 PostgreSQL 数据库用户同名（如已 sudo -i -u postgres 切换），且数据库为本机默认端口 5432。

# 2. 不同场景下的参数补充

场景 命令 说明
已切换 postgres 用户 psql 零参数，直接以 postgres 身份进入同名数据库
普通用户指定数据库用户 psql -U postgres 最少需带 -U 指定用户名
指定用户 + 指定数据库 psql -U postgres -d testdb 同时指定用户和数据库名
远程连接 psql -h 192.168.1.10 -U postgres -d testdb 需额外指定主机地址 -h

# 3. 常用参数速查

参数 全称 说明
-h --host 服务器地址（默认本机）
-p --port 端口号（默认 5432）
-U --username 数据库用户名
-d --dbname 数据库名
-W --password 强制提示输入密码

# 4. 完整写法对照

# 完整写法（远程连接）
psql -h <服务器地址> -p <端口号> -d <数据库名> -U <用户名>

# 本地默认连接（当前系统用户同名数据库）
psql

# 指定用户连接默认数据库
psql -U postgres

# 指定用户 + 指定数据库
psql -U postgres -d testdb

# 5. 常用元命令速查

命令 说明
\l 列出所有数据库
\c dbname 切换到指定数据库
\dn 列出所有模式
\d 列出当前数据库所有表
\d tablename 查看表结构详情
\dt 只列出普通表
\di 列出索引
\du 列出所有用户/角色
\q 退出 psql

提示：\ 开头的命令是 psql 客户端元命令，不是 SQL 语句，不需要以分号结尾；SQL 语句必须以 ; 结尾。

# 5. 删除数据库

-- 删除数据库（无连接时）

-- 强制删除（断开已有连接后再删除）
SELECT pg_terminate_backend(pg_stat_activity.pid)
