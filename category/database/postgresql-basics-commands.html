# 六、psql 常用元命令速查

命令 说明
\l 列出所有数据库
\c dbname 切换到指定数据库
\dn 列出所有模式
\d 列出当前数据库所有表
\d tablename 查看表结构详情
\dt 只列出普通表
\di 列出索引
\du 列出所有用户/角色
\q 退出 psql

提示：\ 开头的命令是 psql 客户端元命令，不是 SQL 语句，不需要以分号结尾；SQL 语句必须以 ; 结尾。
