VMware NAT 网络配置与 IP 速查指南

maiaimei 2026/11/14 VMware

写在前面：如果你第一次接触 VMware 的网络设置，面对"子网 IP""网关""DHCP 池"这些术语感到头大，别慌。你只需要把它想成：VMware 在宿主机里造了一个"小局域网"，虚拟机都住在这个小局域网里。

笔记按 "从外到内、从大网段到单台虚拟机" 的顺序展开，配合生活类比，看完就能上手配。

# 核心概念速查表

名称 通用模板 示例值（你的数据） 通俗理解 能不能给虚拟机用
网络类型 VMnet0/VMnet8/VMnet1 VMnet8 (NAT 模式) 虚拟网卡/交换机；NAT=借宿主机网络上网 —
子网掩码 255.255.255.0 255.255.255.0 决定哪些 IP 算同一个网段（/24） —
网络地址/子网 IP 192.168.x.0 192.168.134.0 整个网段的“名字/标识”，代表网段本身 ❌ 不能
网关 IP 192.168.x.2 192.168.134.2 带虚拟机上网的“出口”（VMware 占用） ❌ 是 VMware 占用的
可用静态 IP 192.168.x.3 ~ 192.168.x.127 192.168.134.3 ~ 192.168.134.127 你手动固定 IP 的“安全区” ✅ 随便挑
DHCP 池 192.168.x.128 ~ 192.168.x.254 192.168.134.128 ~ 192.168.134.254 自动发 IP 的范围（动态分配） ⚠️ 别手动用
广播地址 192.168.x.255 192.168.134.255 网段里“喊一嗓子”所有人都能听到的地址 ❌ 不能
DNS 公共 DNS 114.114.114.114 / 8.8.8.8 域名翻译官（baidu.com → IP） ✅ 配在系统里

# 网络类型：VMnet8（NAT 模式）

VMnet8 是 VMware 给你的虚拟机"虚拟出来的一块网卡 + 一个交换机"。

NAT 模式的意思是：

  • 虚拟机住在一个"私有小网段"里（你这里是 192.168.134.x）
  • 虚拟机上网时，会借宿主机的网络出去（就像家里路由器给手机 NAT 上网一样）
  • 宿主机能访问虚拟机，但外部网络（比如你公司/家里的其他电脑）一般不能直接访问虚拟机

🏠 类比：VMnet8 = 一个"虚拟路由器 + 交换机"，NAT = 它帮你做"地址转换上网"。

# 子网掩码：255.255.255.0（= /24）

子网掩码决定 "哪些 IP 算同一个网段"。

你这里是：

  • 子网掩码：255.255.255.0
  • 前 24 位是"网络部分"，最后 8 位是"主机部分"

所以：

  • 192.168.134.x 里，192.168.134 是网段，x 是主机号
  • 同网段范围：192.168.134.0 ~ 192.168.134.255（共 256 个地址）

# 网络地址/子网 IP：192.168.134.0

这是整个网段的"名字/标识"，代表"192.168.134 这个网段本身"。

  • 它叫 网络地址
  • 不能配给任何机器（不能给虚拟机、不能给网关、不能当 DNS）
  • VMware 界面写"子网 IP"，本质就是让你设定这个网段

📖 术语对照：

  • 网络地址 = TCP/IP 标准术语，指一个网段的逻辑起点（IP 与子网掩码按位与运算的结果）
  • 子网 IP = VMware 虚拟网络编辑器界面上的"俗称/配置项名称"

两者在你这个场景里指的是同一个东西——VMware 让你填"子网 IP"，底层实际就是在设定这个虚拟局域网的网络地址。

# 网关 IP：192.168.134.2

网关 = 这个网段里能带我上网/出网的那台设备。

在 VMware NAT 模式里：

  • 网关通常是 .2
  • 它由 VMware（宿主机里的 VMnet8 / NAT 服务）充当
  • 虚拟机想访问外网（百度、apt 源等），都得把数据包发给它

⚠️ 常见踩坑：把网关写成 192.168.134.1。很多真实路由器确实是 .1，但 VMware NAT 通常是 .2！

# 可用静态 IP：192.168.134.3 ~ 192.168.134.127

这是给你 "手动固定 IP" 的安全区间：

避开了什么 原因
.0 网络地址，不是可用主机 IP
.255 广播地址
.2 网关，VMware 占用
128~254 DHCP 池，避免冲突

✅ 推荐你学习用的地址：

  • 192.168.134.10（好记、稳）
  • 或 192.168.134.11 / 12（以后多台机器扩展）

# DHCP 池：192.168.134.128 ~ 192.168.134.254

DHCP = "自动发 IP 的服务"。

VMware 会自动给"选择 DHCP"的虚拟机发 IP，发的范围就是 DHCP 池：

  • 自动分配范围：128 ~ 254

  • 128 ~ 254：让 DHCP 自动管，⚠️ 你配静态 IP 时必须避开 DHCP 池！

  • 你手动静态：选 3 ~ 127（更安全）

# 广播地址：192.168.134.255

这是一个网段里 "喊一嗓子，所有人都能听到" 的地址（广播）。

  • 用于某些广播通信（ARP、DHCP 等底层协议会用）
  • 不能配给单台机器当静态 IP

# DNS：114.114.114.114、8.8.8.8

DNS = "把域名翻译成 IP"（如 baidu.com → 某个 IP）。

DNS 地址 说明
114.114.114.114 国内常用 DNS，速度快
8.8.8.8 Google 公共 DNS，国内有时解析慢但可用

配完 DNS 后：

  • ping 8.8.8.8 通 → 说明网络通
  • ping baidu.com 通 → 说明 DNS 解析也 OK

# 一句话总结

VMnet8（NAT） 造了一个小局域网：

网段是 192.168.134.0/24（网络地址 .0，广播 .255），

VMware 网关是 192.168.134..2，

DHCP 自动发 192.168.134.128~192.168.134.254，

你手动静态就选 192.168.134.3~192.168.134.127，

DNS 负责域名解析。
