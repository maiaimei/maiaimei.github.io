Linux man 命令笔记

maiaimei 2026/11/8 Linux

在 Linux 中，man（manual 的缩写）是最权威的本地命令文档。

# man 查阅退出

  • 打开手册：输入 man 命令名，如 man ps、man systemctl。
  • 退出手册：按 q 键即可退出；按 h 进入帮助。
  • 翻页与滚动：
    • 使用 上下方向键 逐行滚动。
    • 使用 回车键 向下滚动一行。
    • 使用 空格键 或 Page Down/Page Up 翻页。

# man 页面结构

man 页面的标准结构（以 ps 为例）：

  • NAME：命令名称与一句话简介（如 ps - report a snapshot...）。
  • SYNOPSIS：语法概要（如 ps [options]，展示参数格式）。
  • DESCRIPTION：详细描述（解释了 ps 的 UNIX/BSD/GNU 选项风格，以及 ps -aux 与 ps aux 的区别）。
  • EXAMPLES：使用示例（如 To see every process...）。
  • 后续通常还有 OPTIONS（参数详解）、SEE ALSO（关联命令）等。

# man 搜索技巧

进入 man 页面后，按 / 键进入搜索模式：

  • 输入关键词，如 /aux，按回车，会高亮匹配项。
  • 按 n 键跳转到下一个匹配项，按 N 跳转上一个。
  • 搜索后想清除高亮，随便打一串肯定匹配不到的东西，回车。因为找不到匹配，之前的高亮就"消失"了（实际上是被空结果覆盖了）。

# man 进阶用法

关键字搜索：忘了具体命令名，用 man -k 关键词，会列出相关命令。

# 安装 man 中文手册

# Ubuntu / Debian

sudo apt update
sudo apt install manpages-zh    # 中文 man 包

# CentOS / RHEL / Rocky

sudo yum install man-pages-zh-CN
# 或
sudo dnf install man-pages-zh-CN

# 使用 man 中文手册

安装完后，用 -L 参数指定语言：

man -L zh_CN ps
man -L zh_CN systemctl
1
2

如果 -L zh_CN 没效果，试试 man -L zh 或 man -M /usr/share/man/zh_CN ps

# 配置 man 别名（中英文灵活切换）

为了不破坏原生 man 的英文习惯，同时又能随时查看中文手册，推荐配置 cman 别名。

将以下内容写入 ~/.bashrc 文件（可使用 echo "alias cman='man -L zh_CN'" >> ~/.bashrc 快速添加）：

alias cman='man -L zh_CN'
1

保存后，执行以下命令让配置立即生效：

source ~/.bashrc
1

中英文随时切换，互不干扰 ✅

cman ps          # 中文 man
man ps           # 英文 man
1
2

# 命令 -h / 命令 --help vs man 命令

-h / --help 看“怎么用”，man 看“怎么懂”。-h 是“说明书封面”，man 是“完整说明书”。

对比项 命令 -h / 命令 --help man 命令
来源 命令自带（通常由开发者写在源码里） 系统手册页（系统级文档，由发行版 / 上游维护）
内容 参数列表、简短说明 完整说明、原理、示例、注意事项
长度 短（一屏以内） 长（可能几屏到几十屏）
是否联网 否 否
是否一定存在 不一定（有的命令没有） 大多数命令都有
适合场景 临时查参数、快速回忆 深入学习、排错、写配置
