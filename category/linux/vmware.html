# VMware 网络模式

VMware 提供三种网络工作模式，适用场景各异：

模式 核心特点 优点 缺点 适合场景 初学者建议
桥接模式（Bridged） 虚拟机与物理机处于同一网段，如同接入同一交换机；IP 需与物理机同网段，网关/DNS 通常与物理网卡一致。 网络访问权限最大，灵活性高，虚拟机与宿主机可互相访问。 消耗较多 IP 资源，在 IP 管理严格的网络环境中可能不适用。 搭服务器，局域网测试，局域网互通 家庭网络可用
网络地址转换模式（NAT） 虚拟机通过宿主机的 NAT 功能访问外部网络，外部网络不直接访问虚拟机。 节省 IP 资源，适用于 IP 管理严格的场景。 虚拟机网络访问可能受限（如无法被局域网其他机器直接访问）。 日常开发，装环境，能上网、不占 IP ✅ 首选
仅主机模式（Host-Only） 创建封闭虚拟网络，仅允许虚拟机与宿主机通信，无法访问外部网络。 完全隔离，适合内部测试、开发环境。 无法连接外网。 完全隔离，隔离靶场，安全测试 不推荐新手

# 虚拟机与宿主机网络互通问题

现象：虚拟机 ping 不通宿主机

解决（Windows 宿主机）： 控制面板 → 系统和安全 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 启用 “虚拟机监控(回显请求-ICMPv4-In)” 规则。

好，我不直接喂结论，教你以后自己从官网查到“标准答案”的方法。分两条线：Ubuntu 网络配置、VMware 网络模式。

一、Ubuntu 固定 IP：去哪查、怎么查

  1. 先认准“官方文档入口”

  • Ubuntu 官方文档站：

    • https://documentation.ubuntu.com/server/network-configuration/ （Server 网络配置）
    • https://help.ubuntu.com/ （老入口，会跳转到新文档）

  • Netplan 官方文档（Ubuntu 18.04+ 网络实际用的是它）：

    • https://netplan.readthedocs.io/
    • 静态 IP 专题：Netplan 文档里搜 “Using static IP addresses”

思路：Ubuntu 本身不“发明”配置语法，静态 IP 是 Netplan YAML 规范，所以查 Netplan 比查博客准。

  1. 官网自查步骤（照着点）

  2. 打开 https://netplan.readthedocs.io/

  3. 左侧点 How-to guides / Examples

  4. 找标题：

    • “Configure a static IP address”
    • “DNS servers and search domains”
    • “Default route / gateway”

  5. 看它给的字段名：

    • "addresses"
    • "routes: to: default, via:"
    • "nameservers: addresses"

  6. 再回 Ubuntu 文档确认：文件放 "/etc/netplan/*.yaml"，命令是 "netplan try" / "netplan apply"

  7. 系统里“反查官网术语”

man netplan # 看本地有没有 man netplan --help

官网和本地命令对得上，说明你没看错文档。

  1. 版本差异怎么自己确认
  • 18.04 老文档用 "gateway4"
  • 20.04+ 新文档用 "routes:" → 官网页面通常会写 “since version x”，你看自己 "lsb_release -a" 再选

二、VMware Workstation 网络：去哪查

  1. 官方文档入口（Broadcom 接手后）

  • Broadcom VMware TechDocs： https://techdocs.broadcom.com/ 搜索：VMware Workstation Pro

  • 直接路径示例：

    • Workstation Pro → Using VMware Workstation Pro → Configuring network connections
    • NAT 说明：https://techdocs.broadcom.com/us/en/vmware-cis/desktop-hypervisors/workstation-pro/25H2/using-vmware-workstation-pro/configuring-network-connections/configuring-network-address-translation-1.html
  1. 查什么关键词

在官网搜索框输：

  • "Workstation Pro bridged networking"
  • "Workstation Pro NAT port forwarding"
  • "virtual network editor VMnet8"
  • "static IP in virtual machine"
  1. 官网会告诉你（而不是我记的）
  • 桥接 = 虚拟机在外部网络有独立 IP
  • NAT = 默认 VMnet8，虚拟机用私有网段，主机做地址转换
  • 仅主机 = 只能和主机通信
  • 固定 IP 时：NAT 要进“虚拟网络编辑器”看网关范围，或做端口映射
  1. 本地对照官网
  • VMware 菜单：编辑 → 虚拟网络编辑器
  • 看 VMnet0（桥接）、VMnet8（NAT）的网段
  • 官网说“NAT 默认 192.168.x.x”，你本地看到的一样，就证明查对了

三、给你一套“自查心法”

以后遇到任何 Linux/虚拟机问题，按这个顺序：

  1. 先查官方文档站（不查 CSDN/知乎）

    • ubuntu.com / documentation.ubuntu.com
    • netplan.readthedocs.io
    • techdocs.broadcom.com

  2. 用“配置对象+动作”搜

    • 错：”Ubuntu 怎么设IP“
    • 对：”netplan static ip addresses routes nameservers example“

  3. 看官网给的字段名，不是抄命令

    • 理解 "addresses/routes/nameservers" 是什么

  4. 本地用 --help / man / 菜单验证

  5. 版本对齐：文档写 22.04，你用 24.04，先确认没弃用

四、你可以马上练一次（不让我给答案）

打开这两个页面，自己找答案：

  1. https://netplan.readthedocs.io/en/stable/examples.html → 找到 “Static IP address” 那段，抄字段结构（不抄 IP 数值）
  2. https://techdocs.broadcom.com/ 搜 “Workstation Pro NAT” → 回答自己：NAT 模式虚拟机为什么外网访问不到？

你更想先练“读 Netplan 官方示例并改出适配配置”，还是“在 VMware 官方文档里定位网络模式说明”？
